# Topics

Add a topic under **Inbox**, one bullet each, with any notes, facts, links or a preferred posting time.
The drafting routine picks up everything in the Inbox, opens a PR of drafts, and moves the bullet to **Drafted**.

Optional tags at the end of a bullet:
- `[when: 2026-10-09 09:00 +02:00]` publish no earlier than this
- `[only: linkedin, x]` draft just for these platforms
- `[image: social/media/photo.jpg]` local image (Bluesky, Mastodon)
- `[image_url: https://…]` public image link (needed for Instagram; also Threads, Facebook, Google Business)
- `[video: social/media/clip.mp4]` needed for YouTube
